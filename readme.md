# Java Collections Framework

### A practical collection of Java exercises from the MK Code Club channel

This repository contains the hands-on code examples used to teach the **Java Collections Framework** on the **MK Code Club** channel. Each lesson is a small, focused Java program that can be compiled and run independently, making it easy to follow along, experiment, and compare collection types.

The examples move from everyday list operations to sets, maps, stacks, queues, and useful helper methods from the `Collections` class.

---

## What You Will Learn

- How to create, read, update, delete, and traverse collections
- The difference between ordered, sorted, and unordered collections
- How collections handle duplicate values
- How to store key-value pairs with maps
- How stack and queue data structures work
- How to use common methods from `java.util.Collections`
- How to choose a collection based on the behavior your program needs

## Collection Quick Guide

### Lists

Lists keep elements in a sequence and allow duplicate values.

| Collection | Best known for | Ordering |
| --- | --- | --- |
| `ArrayList` | Fast indexed access and general-purpose lists | Insertion order |
| `LinkedList` | Adding or removing elements at the beginning or end | Insertion order |

### Sets

Sets store unique values and do not allow duplicates.

| Collection | Best known for | Ordering |
| --- | --- | --- |
| `HashSet` | Fast general-purpose uniqueness checks | No guaranteed iteration order |
| `LinkedHashSet` | Uniqueness while retaining insertion order | Insertion order |
| `TreeSet` | Uniqueness with automatic sorting | Sorted order |

### Maps

Maps associate a unique key with a value.

| Collection | Best known for | Key ordering |
| --- | --- | --- |
| `HashMap` | Fast general-purpose key-value lookup | No guaranteed iteration order |
| `LinkedHashMap` | Key-value lookup while retaining insertion order | Insertion order |
| `TreeMap` | Key-value lookup with sorted keys | Sorted order |

### Special-purpose structures

- **Stack:** Last In, First Out (LIFO). The most recently added item is removed first.
- **Queue:** First In, First Out (FIFO). The earliest added item is removed first.

## Requirements

- Java Development Kit (JDK) 8 or newer
- A terminal, command prompt, or Java-compatible IDE

No third-party libraries, build tools, or database setup are required. Every example uses classes from the standard Java library.

Check your Java installation with:

```bash
java -version
javac -version
```

---

## Run an Exercise

Open a terminal in the repository directory and compile the file you want to explore:

```bash
javac T1_ArrayList.java
java T1_ArrayList
```

Replace `T1_ArrayList` with any class name from the course roadmap.

### Compile every exercise

On macOS or Linux:

```bash
javac *.java
```

On Windows PowerShell:

```powershell
javac *.java
```

Run any compiled lesson, for example:

```bash
java T8_TreeMap
```

To remove generated bytecode files after experimenting:

```powershell
Remove-Item *.class
```

On macOS or Linux, use:

```bash
rm *.class
```

## Suggested Learning Path

1. Start with `ArrayList` and `LinkedList` to understand sequence-based collections.
2. Compare `HashSet`, `LinkedHashSet`, and `TreeSet` to see how uniqueness and ordering differ.
3. Practice key-value operations with `HashMap`, `LinkedHashMap`, and `TreeMap`.
4. Learn LIFO and FIFO behavior with `Stack` and `Queue`.
5. Finish with `T11_Important_Methods.java` and apply utility methods to a list.
6. Modify the values, add new elements, and predict the output before running each program.

---

## Practice Challenges

After completing the examples, try these small extensions:

- Change the examples from `Integer` values to `String` values.
- Add duplicate values and observe how lists and sets respond differently.
- Insert map entries in a different order and compare `HashMap`, `LinkedHashMap`, and `TreeMap`.
- Add a `for-each` loop to every collection example.
- Add a `containsValue` check to the map examples.
- Build a simple task manager using a `Queue`.
- Build a browser-history simulation using a stack.
- Sort a custom list in ascending and descending order.
